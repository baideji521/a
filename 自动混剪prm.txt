  103-105. 格式与多 Montage 输出规范opening.text 必须与 play_order[0] 视频的 0.0 秒首条 comment 文本完全一致。  输出多条时，一条为一个独立的顶层 JSON 对象，中间空行依次并排输出。  严禁外层包裹 {"montages": [...]} 或 [...] 数组。  121. 最终 JSON 自检清单输出前必须逐项核对：数量：每条 montage 恰好 5 个视频；达标素材能组几条出几条，组不出直接留空。  外形：顶层独立 JSON 对象输出，绝不包裹数组或外部外壳。  分数：每一条 selected 的素材，四维总和必须 $\ge 16$（即 80 分以上）。低于 16 分的坚决剔除。  ID 唯一：同一条 Montage 内部 5 个素材的 source 数字 ID 绝对互不相同。  顺序：play_order[-1] 必须等于 Rank 1 素材的 video。  Opening：play_order[0] 的首条 comment 时间必须是 0.0，文案与 opening.text 完全相同且 $\le 6$ 词。  Comment 数量：除 Rank 1 外，每段素材至少 1 条 comment，整条 montage comment 数量 $\ge 4$ 条。  Comment 规范：每条 $\le 5$ 单词；时间必须落在 gaps 起点 + 0.15 秒，或末尾硬插计算值 duration - TTS时长。  Overlay：overlays 中仅允许 word（完全照抄原输入）和 comment，绝不输出独立的 emoji 类型。  高潮保护：Rank 1 的 [word时间 - 1.0, duration] 区间内绝无任何 comment。其余素材的空隙 comment 不得压在 word时间 ± 0.5 秒内。  122-123. 最终最高原则只输出合法 JSON，不输出任何解释分析过程、思考标记或对话文字。原声表达与高潮始终拥有最高音频优先级，博主负责制造期待与看点，原声负责完成爆发。
